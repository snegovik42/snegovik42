## Проекты

### 🚕 [black-russia](https://github.com/snegovik42/black-russia) — браузерная мини-игра

Фанатская 2D-игра по мотивам Black Russia: ночной открытый город, заказы такси, угоны, полиция и погони. Полностью на Canvas и ванильном JavaScript, с отдельным сенсорным управлением для телефонов и сохранением прогресса.

[Играть в браузере](https://snegovik42.github.io/black-russia/) · `HTML` · `CSS` · `JavaScript`

### 🧊 [sneg](https://github.com/snegovik42/sneg) — свой язык программирования

Интерпретатор, написанный с нуля: лексер, парсер, дерево разбора, замыкания, области видимости. Есть компиляция в `.snegc` (аналог `.pyc`), REPL и собственный редактор с подсветкой синтаксиса и кнопкой «Запустить».

2000 строк, 50 тестов, сборка в один exe без зависимостей.

`Python` · `Tkinter` · `PyInstaller` · [скачать v0.1.0](https://github.com/snegovik42/sneg/releases/tag/v0.1.0)

🤖 Сделано с помощью ИИ

`HTML` · `CSS` · `JavaScript`
